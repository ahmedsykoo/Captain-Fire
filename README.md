# FairKM — نسخة أولى (v1)

## اللي اتبنى في النسخة دي
- Accessibility Service يقرأ عرض السعر والمسافة من inDrive (`sinet.startup.inDriver`)
- Overlay عائم بتصميم Material 3 قابل للسحب، بيعرض:
  - السعر/كم الصافي (بعد خصم عمولة المنصة)
  - حالة السعر (كويس / تحت الهدف) بلون واضح
  - تفاصيل: السعر المعروض، المسافة، نسبة العمولة، الصافي الكلي، هدفك
- شاشة إعدادات بتسمح تحدد **نسبة عمولة كل منصة** (inDrive, Didi, Uber, Swvl) + هدف السعر لكل واحدة، وتتخزن بشكل دائم (DataStore)

## هوية بصرية جديدة
- ألوان: أخضر زمردي (Emerald) + كهرماني (Amber) — مختلفة عن أي تطبيق منافس
- Typography وMaterial 3 كامل، دعم Dark Mode تلقائي، RTL

## البناء
المشروع مفيهوش `gradle-wrapper.jar` (محتاج إنترنت لتنزيله). في طريقتين:

### 1) عبر GitHub Actions (الأسهل — زي ما عملنا في NetFare)
1. اعمل push للمشروع ده لريبو جديد على GitHub
2. الـ workflow في `.github/workflows/build.yml` هيشتغل تلقائي ويبني APK
3. حمّل الـ APK من تبويب Actions → Artifacts

### 2) لو عندك Android Studio على جهاز
افتح المجلد، خليه يعمل Gradle Sync (هيولد الـ wrapper لوحده)، وابني APK عادي.
